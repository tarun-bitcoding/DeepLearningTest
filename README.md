# Chest X-Ray Classification: COVID-19, Pneumonia & Normal

![X-Ray Image](https://www.kaggleusercontent.com/code/output/datasets-prashant268-chest-xray-covid19-pneumonia/images/6.jpg)

## 📁 Dataset

This project uses the [Chest X-Ray: COVID-19, Pneumonia & Normal](https://www.kaggle.com/datasets/prashant268/chest-xray-covid19-pneumonia/versions/1) dataset from Kaggle. The dataset includes chest X-ray images categorized into three classes:

- **COVID-19**
- **Pneumonia**
- **Normal (healthy lungs)**


## 🚀 Project Goals

- Build and train a deep learning model to classify chest X-ray images.
- Compare performance between different models (e.g., CNN, ResNet, MobileNet).
- Evaluate model accuracy using validation and test sets.
- Visualize predictions and confusion matrix.
